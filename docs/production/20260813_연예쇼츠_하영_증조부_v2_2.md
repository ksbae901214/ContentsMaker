## 2. 기획 원칙 — 단죄 프레임을 쓰지 않는다

"친일파 후손 손절" 프레임은 **쓰지 않기로 결정**했다. 명예훼손·여론재판 리스크가
크고, 기사들이 짚는 실제 논점도 그게 아니다.

대신 **"100년 전 조상의 행적, 후손 책임은 어디까지인가"** 를 축으로 잡았다.
여론이 정확히 반으로 갈린 사안이라 CTA 선택지형에 그대로 맞고, 더 안전하면서
동시에 더 좋은 콘텐츠가 된다.

편집에 박아 넣은 안전장치 3가지:

1. **'친일파'로 단정하지 않음** — "친일 단체 명단 등재"라는 확인된 사실로만 서술
2. **반론 씬을 구조에 포함**(scene 2) — 곁다리 한 줄이 아니라 독립 씬. 빠지면 단죄 콘텐츠가 된다
3. **결론 문장을 만들지 않음** — 일어난 일로 끝내고 판단은 CTA로 넘김

## 4. 제작 중 발견한 문제 4건

### ① yt-dlp 전면 403 (인프라, 해결)
모든 소스 다운로드가 `HTTP 403 Forbidden` 으로 실패. 시도 순서와 결과:

1. yt-dlp 업그레이드 (2026.06.09 → 2026.07.04) → **실패**
2. `player_client` 교체 (web_safari/tv/ios/mweb/web) → 포맷 없음 또는 DRM, **실패**
3. `--cookies-from-browser chrome` → 경고에서 원인 노출
4. **`--remote-components ejs:github`** → **해결**

원인은 YouTube의 n-sig **JS 챌린지**였고, yt-dlp가 솔버(EJS)를 기본 배포에
넣지 않아 원격 컴포넌트를 켜야 했다. deno는 이미 설치돼 있었다.
→ `render_political_v2_1.py` 의 `YTDLP_CHALLENGE_ARGS` 로 반영(V2.2도 재사용).

### ② 자막이 실제 음성과 불일치 (해결)
기획 단계에서 자막을 *"고종 황제를 진료하셨다"* 로 썼으나, 확보한 클립의 실제
육성은 *"증조할아버지부터 의사를 하셨다고 들었어"* 였다. 자막을 음성에 맞춰 수정.
→ **교훈: 자막은 기사 문구가 아니라 확보한 클립의 실제 발언에 맞춰야 한다.**

### ③ CTA 자막이 방송 번인 자막과 겹침 (해결)
TTS 씬의 `subtitle_position` 기본값은 `""`(중앙 하단, position_y 0.652)인데,
연합뉴스TV 클립은 화면이 세로로 커서 그 위치가 영상 안쪽에 떨어져 번인 자막과
겹쳤다. → 해당 두 씬에 `"subtitle_position": "bottom"` 지정 후 재렌더.

### ④ BGM이 소재와 어긋남 (지침으로 반영, 재렌더 안 함)
**배포본은 `funny_2.mp3`(코믹 BGM)로 나갔다.** 친일 논란 소재에 부적절.

원인은 036에서 넣은 카테고리 기본값 `entertainment → emotion_type: "funny"` 였다.
BGM은 `select_bgm_for_script` 가 `emotion_type` **하나만** 보고 고른다.

V2.1/V2.2는 배경색을 `bg_colors`, 자막색을 씬별 `color` 로 따로 지정하므로
**`emotion_type` 은 사실상 BGM 스위치**다 — 바꿔도 화면은 그대로고 BGM만 바뀐다.

| 소재 톤 | `emotion_type` |
|---|---|
| 사실 전달·중립 검증 | `relatable` |
| 대립·비판·규탄 | `angry` |
| 비극·회한·서사 | `touching` |
| 축하·가벼움 | `funny` — **논란 소재 금지** |

→ config는 `relatable` 로 교정했으나 **배포된 영상은 재렌더하지 않았다**
(사용자 지시). 다시 렌더하면 `relatable_2.mp3` 로 바뀐다.
템플릿 3종·README·CLAUDE.md에 지침 반영 완료.

## 6. 이 편에서 정해진 운영 규칙

### 연예쇼츠는 V2.2만 만든다 (사용자 확정)
V2.1은 영상의 65%가 TTS 논평이라 연예 소재에서 **논평이 곧 단죄로 읽히고**
명예훼손 노출이 V2.2보다 크다. V2.2는 육성 릴레이 구조상 "사실을 보여주고
판단은 시청자에게"가 편집에서 자연히 나온다.

또한 V2.1의 위험을 상쇄하려면 나레이션을 보도체로 되돌려야 하는데, 그러면
030 P3(탈보도체) 개선을 잃는다 — **안전하게 만들면 재미없고, 재미있게 만들면
위험한** 구조라 이 소재군에는 맞지 않는다.

→ 034 플랫폼 분리(V2.2 유튜브 / V2.1 틱톡)에서 연예의 V2.1 자리는 비운다.
정치·경제·사회는 종전대로 병행 가능.

### CTA 위치 — 이 편은 예외
035는 CTA를 40% 지점에 자동 삽입한다(실측 근거: 말미 CTA는 도달 자체가 안 돼
최근 18편 댓글율 0.24%). **이 편은 사용자 지시로 맨 마지막에 배치**했다.
`apply_cta` 는 구조상 마지막 씬 뒤에 넣지 않으므로 `cta` 블록을 쓰지 않고
scenes 끝에 tts 씬으로 직접 넣었다.

→ **말미 CTA의 반례 검증용**이다. 이 편 댓글율을 최근 평균 0.24%와 비교해
40% 복귀 여부를 데이터로 판단할 것.
