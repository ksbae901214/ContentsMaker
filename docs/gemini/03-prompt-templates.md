# 단계별 복붙 프롬프트 (Gemini용)

`02-gem-instructions.md`로 Gem을 만든 뒤, 아래 프롬프트를 순서대로 넣으면 한 편이 완성된다.
Gem 없이 일반 대화창에서 쓸 때는 **프롬프트 0**을 먼저 넣어 규칙을 주입한다.

---

## 프롬프트 0 — 규칙 주입 (Gem을 안 쓸 때만)

```
너는 한국 정치 유튜브 쇼츠 제작 디렉터야. 아래 규칙을 이번 대화 내내 지켜줘.

[소재] 결과가 난 사건만 (철회·사퇴·번복·역전·통과·부결·구속·선고·컴백).
       'A가 B를 직격/저격' 공방형은 조회수가 1,100대에서 멈춘다는 게 실측이야.
[길이] 총 38~42초 (아웃트로 4초 포함). 나레이션은 1.1배속 기준 8.1자/초로 역산.
[CTA]  전체의 40% 지점에 1회. 편 가르는 선택지형(①/②·누구 잘못·어느 쪽) 필수,
       열린 질문 금지, 나레이션 32자 이내. 마지막 씬에는 절대 넣지 않는다.
[제목] 12~20자, 해시태그 금지, 보도체(~했다/~합니다/~논란/~공방) 금지, 실명 1~2개.
[문체] 보도체 대신 대립 서사체(주장→반박→역공), 문말 다양하게.
[사실] 확인된 것만 단정, 해석은 "~로 보인다"로 분리, 출처 URL 명시.
[영상] 9:16 1080x1920 레터박스. 육성 클립 훅 1~10초·본문 1~12초, 문장 끝맺음까지 포함.
       육성 씬 자막은 하단(0.78)에 노란색. 클립마다 [화자] 라벨.
[금지] 자동 업로드, 타임스탬프 추측, 기사 재인용 자막.

이해했으면 "준비 완료"만 답하고 기다려.
```

## 프롬프트 1 — 소재 판정

```
오늘의 소재 후보야. 쇼츠로 만들 가치가 있는지 판정해줘.

[뉴스 제목] ...
[기사 본문/요약] ...
[기사 URL] ...
[댓글 수] ...

판정 형식:
1) 결과 문장 한 줄 (무엇이 어떻게 끝났는가) — 없으면 "소재 부적합" + 대안 각도 3개
2) 확정 사실 3~5개 (각각 어떤 출처로 확인 가능한지)
3) 등장인물 2~4명 (실명)
4) 대립 축: A 주장 ↔ B 반박
5) CTA 선택지 ① ② 초안
6) 예상 리스크 (미확정 혐의·명예훼손 소지·정정 가능성)
```

여러 후보를 한 번에 줄 때:

```
아래 이슈 5건 중 쇼츠 소재로 가장 좋은 1건을 골라줘.
기준: ①결과가 났는가 ②당사자 육성 영상이 존재할 만한가 ③댓글이 갈리는가.
각 후보에 대해 3기준 O/X와 한 줄 근거를 표로 주고, 마지막에 선택과 이유를 써줘.

1. ...
2. ...
```

## 프롬프트 2 — 원본 영상 탐색 계획

```
아래 소재로 쓸 유튜브 원본 영상을 찾을 계획을 세워줘.

[소재 카드] (프롬프트 1의 결과 붙여넣기)

출력:
1) 소스 키별 검색어 3~5개 — 형식은 "인물 + 발언 키워드 + 장면 종류"
   여야 반응이 한 편에 들어 있는 뉴스 리포트가 있으면 최우선으로 제안
2) 각각의 yt-dlp 명령 (720p 제한, 20~900초 필터)
3) 어떤 장면이 잡히면 성공인지 (예: "국민의힘 대변인 브리핑 스탠딩 컷")
4) 인물 확인용 검증 프레임 추출 명령
```

유튜브 URL을 직접 줄 수 있을 때:

```
이 영상에서 "<발언 키워드>" 대목이 어디쯤인지 후보 구간을 3개 알려줘: <URL>
※ 네 타임스탬프는 드리프트가 있으니 ±10초 탐색 힌트로만 쓸게.
각 후보마다 그 구간에 인물 표정 변화(웃음/한숨/야유/침묵)가 있는지도 같이 알려줘.
```

## 프롬프트 3 — 씬 구성 + 컷 계획

```
V2.2(육성 릴레이) 포맷으로 씬을 구성해줘.

[소재 카드] ...
[확보한 소스] joguk=조국 기자회견(9분), leejs=이준석 인터뷰(12분), chA=채널A 리포트(7분)
[실측한 발언 구간] joguk 42.0~45.5 "일베는 기계적으로 노" / leejs 128.0~134.0 "죽창 들자던 사람이" / ...

출력 1) 씬 구성표
| 씬 | 모드 | 소스 | 시작초 | 길이 | 자막(2줄) | 색 | 화자 | 나레이션 |
- 구성: 클립(훅) → 클립(반박) → [CTA 40%] → 클립(재반박) → TTS(팩트 정리)
- 클립 길이 합계와 TTS 예상 시간을 더해 최종 길이를 계산하고 42초 캡을 검산할 것
- 육성 오디오 비중 %도 계산해서 65% 넘는지 확인

출력 2) 각 클립의 ffmpeg 컷 명령 (9:16 레터박스, 육성은 오디오 유지 / TTS 씬은 -an)
출력 3) 문장 끝 확인용 silencedetect 명령
```

## 프롬프트 4 — 논평(나레이션) 작성

```
아래 씬 구성표의 TTS 씬 나레이션을 써줘.

[씬 구성표] ...
[쓸 수 있는 시간] TTS 총 __초 → 1.1배속 8.1자/초 → 약 __자

조건:
- 보도체 금지. 주장→반박→역공의 대립 서사체, 문말 다양하게
- 확정 사실만 단정, 해석은 "~로 보인다"
- 마지막 씬은 팩트 정리로 닫기 (댓글 유도 문구 넣지 말 것)
- 각 씬 나레이션 뒤에 (글자수/예상초)를 표기하고, 마지막에 총합과 캡 초과 여부를 판정
- 화면 자막도 함께 (2줄, 줄당 21자 이내, 강조 단어 2개 이내)
```

길이가 넘칠 때:

```
총 __초로 __초 초과야. 약 __자를 줄여줘.
씬을 빼지 말고 문장을 압축하는 방향으로. 어떤 정보를 버렸는지도 알려줘.
```

## 프롬프트 5 — 제목 · CTA · 패키징

```
아래 영상의 업로드 패키지를 만들어줘.

[씬 구성표 + 나레이션] ...

1) 제목 A/B 2안
   - 12~20자, 해시태그 금지, 보도체 금지, 실명 1~2개
   - 결과어(결국/끝내/만에/철회/사퇴/역전/컴백…)가 들어가야 함
   - A안은 감정훅형, B안은 호기심형
   - 각 안마다 왜 이 프레임인지 한 줄
2) 중반 CTA (40% 지점에 삽입)
   { "text": "화면 자막 2줄", "voice": "나레이션 32자 이내", "hl": [...], "at_frac": 0.4 }
   - 편 가르는 선택지형(①/②) 필수
3) 설명란: 요약 2~3줄 + "출처: 채널 — 영상 제목" + URL + 해시태그 3~4개
4) 고정댓글 (CTA와 같은 질문)
5) 썸네일 지시: 어느 씬 몇 초 지점의 어떤 표정을 쓸지
6) 자가 체크리스트 판정 (길이/CTA/제목/소재/육성비중/자막위치/출처)
```

## 프롬프트 6 — config JSON 생성 (이 저장소를 쓸 때)

```
지금까지 확정한 내용을 render_political_v2_2.py용 config JSON으로 만들어줘.
스키마는 업로드한 _template_v2_2.json을 따르고, 아래를 지켜줘:

- slug: YYYYMMDD_<주제영문>_v2_2
- scenes[0]은 mode:"clip" (훅), 마지막은 mode:"tts" (팩트 정리)
- clip 씬: source / start_sec / duration / text / speaker / hl
- tts 씬: source / frac 또는 start_sec / text / voice / color / emph
- top-level: yt_title, yt_title_alt, persons, source_channel, source_title,
  youtube_url, cta, sources, tts_speed(1.1)
- 주석은 "_comment" 키로만

JSON만 출력해줘. 확실하지 않은 초 단위 값은 그 자리에 "TODO_실측" 문자열을 넣어줘.
```

생성 후 로컬 실행:

```bash
PYTHONPATH=. .venv311/bin/python scripts/render_political_v2_2.py \
    scripts/political_v2_configs/<이름>.json download
#  → _verify/clip_NN.mp4 청음 확인 (문장이 끝맺어지는가)
PYTHONPATH=. .venv311/bin/python scripts/render_political_v2_2.py \
    scripts/political_v2_configs/<이름>.json render
#  → data/political_pro/<slug>/upload_package.md 확인 후 수동 업로드
```

## 프롬프트 7 — 사후 점검

```
완성된 영상의 자막·나레이션 전문이야. 업로드 전 마지막 점검을 해줘.

[전문] ...
[최종 길이] __초  [육성 비중] __%  [제목] ...  [CTA 위치] __%

체크: 길이 38~42초 / CTA 40%±10% 선택지형 / 제목 비보도체·해시태그 없음·결과어 포함 /
소재 결과형 / 육성 비중 65%↑ / 사실 단정 오류 / 명예훼손 소지 표현 / 출처 표기
문제 있으면 수정안을 함께.
```

## 다른 주제로 재사용하기

정치 외 주제(경제·사회·연예)로 옮길 때 바꿀 것은 다음 4가지뿐이다.

| 항목 | 바꿀 내용 |
|---|---|
| 소재 게이트 | '결과가 난 사건' 기준은 유지, 엔티티 목록만 그 분야로 교체 |
| 소스 검색어 | 인물 대신 브랜드·기관·현장 키워드 |
| CTA 선택지 | 진영 대신 그 분야의 대립 축(예: 소비자 vs 기업) |
| 톤 | Charon 뉴스캐스터 톤 → 주제에 맞는 스타일 프롬프트로 교체 |

길이 캡·자막 규칙·립싱크 보정·TTS 설정은 분야와 무관하게 그대로 쓴다.
